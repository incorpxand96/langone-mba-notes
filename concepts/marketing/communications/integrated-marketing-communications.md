# Integrated Marketing Communications

## Definition

Integrated marketing communications coordinates multiple customer-facing elements around one strategic positioning.

Integration means **coherent meaning**, not identical execution.

## Framework

For each element define:

- target;
- journey stage;
- behavioral objective;
- message;
- channel role;
- metric.

Potential elements include paid media, owned media, earned media, PR, promotion, events, retail, packaging, direct, and digital.

## How I Think About It

The best integrated campaigns are systems.

Each element should do a job that another element does not do as well.

The question is not:

> "Are we on every platform?"

It is:

> **"Does each element reinforce the positioning and move the customer?"**

## Rules of Thumb

- Start with positioning.
- Give each channel a role.
- Adapt execution to platform.
- Preserve the big idea.
- Treat packaging and experience as media.
- Design customer participation intentionally.
- Remove redundant activity.
