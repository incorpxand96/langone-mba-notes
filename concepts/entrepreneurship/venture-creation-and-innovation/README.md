# Venture Creation & Innovation

This branch will capture entrepreneurship through **creation rather than acquisition**.

I am intentionally not filling it with generic startup frameworks yet. It should grow from the MBA material I actually want to retain, including work from New Products, Digital Strategy, Omnichannel Marketing, Strategy, and related projects.

## Questions This Branch Should Eventually Answer

- How do I identify an opportunity worth pursuing?
- How should customer problems be defined?
- What evidence constitutes product-market fit?
- How should experimentation reduce uncertainty?
- How do distribution and go-to-market choices shape the product itself?
- When should a product be standardized versus customized?
- How do pricing and business-model choices affect adoption?
- When does growth create durable advantage rather than merely scale activity?
