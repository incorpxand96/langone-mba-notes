# Network Effects and Tipping

## Network Effect

The value of a product/platform changes with participation.

## Cross-Side

More users on one side increase value to the other.

## Same-Side

More same-side users can create:

- positive value;
- congestion/competition.

## Winner-Take-All Conditions

Tipping is more likely when:

- network effects are strong;
- multi-homing costs are high;
- differentiation needs are weak.

## Reinforcement

Success can create:

`more users → more complements/value → more users`

This is positive feedback.

## Caveat

First mover is not sufficient.

The platform still needs:

- cost/differentiation advantage;
- relationships;
- reputation;
- cash;
- viable economics.

## Principle

> **Scale becomes strategically powerful when it raises both economic efficiency and customer value.**
