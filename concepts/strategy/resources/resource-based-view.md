# Resource-Based View

## Definition

Competitive advantage can arise from firm-specific:

- physical assets;
- intangible assets;
- capabilities.

## Core Tests

- valuable;
- rare;
- difficult to imitate;
- organized to exploit.

## Additional Tests

- durability;
- appropriability;
- substitutability;
- competitive superiority.

## Why Imitation Can Be Hard

- physical uniqueness;
- path dependence;
- causal ambiguity;
- economic deterrence.

## Context

Resource value depends on the environment.

A resource that created advantage yesterday may lose value after:

- technology shifts;
- customer changes;
- industry restructuring.

## Principle

> **Resources create advantage only when they enable a superior strategy in the relevant competitive context.**
