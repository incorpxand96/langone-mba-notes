# Best-Owner Test

## Question

> **Who can create the most value from this business?**

Possible owners include:

- standalone public ownership;
- strategic parent;
- PE sponsor;
- family;
- state;
- employees;
- another corporate parent.

## Principle

> **The strategic hurdle is not "Can we add value?" but "Can we add more value than the next-best owner?"**
