# Value-Based Strategy

## Value Creation

For the complete chain of participants:

`Value Created = WTP - Opportunity Cost`

## Value Appropriation

Bargaining determines how the created value is divided.

## Added Value

A participant has added value when total system value falls if that participant is removed.

This gives the participant bargaining leverage.

## Symmetry

Analyze both:

- downstream customers;
- upstream suppliers, including employees.

## Principle

> **Competitive advantage is strongest when the firm creates an unusually large pie and remains difficult to replace when the pie is divided.**
