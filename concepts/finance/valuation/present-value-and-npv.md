# Present Value and NPV

## Present Value

Value a future cash flow by discounting at an appropriate required return.

`PV = Σ CFt/(1+rt)^t`

## Net Present Value

`NPV = PV of future cash flows − Initial Investment`

Decision rule:

- `NPV > 0` → creates value relative to required return;
- `NPV < 0` → destroys value relative to required return.

## Why NPV Is Powerful

NPV combines:

- magnitude;
- timing;
- risk;
- alternative opportunities

into one decision framework.

## Operating Connection

Operational improvements create value only insofar as they improve expected future cash flows or reduce economically relevant risk.
