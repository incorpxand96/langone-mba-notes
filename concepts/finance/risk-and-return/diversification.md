# Diversification

## Definition

Diversification reduces portfolio risk by combining assets whose returns do not move perfectly together.

## Core Insight

Portfolio expected return is a weighted average.

Portfolio risk depends on covariance.

Therefore the relevant question when adding an asset is:

> **How does it co-move with what I already own?**

## Limits

Diversification can reduce:

- company-specific;
- security-specific;
- idiosyncratic

risk.

It cannot eliminate common systematic shocks.

Correlations can also rise during crises.

## Rule

> **Owning many assets is not the same thing as being diversified.**
