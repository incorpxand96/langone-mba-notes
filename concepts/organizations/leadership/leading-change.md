# Leading Change

## Change Sequence

- create urgency;
- form a coalition;
- create vision;
- communicate;
- empower action;
- create short-term wins;
- consolidate;
- institutionalize.

## Pull and Push

Pull:

- inquire;
- frame;
- appeal to emotion.

Push:

- assert;
- involve;
- appeal to reason.

## Coalition Logic

Target the movable middle.

Build:

- common ground;
- relationships;
- coalition pressure.

## Principle

Change is not just a plan.

It is a shift in:

- beliefs;
- behavior;
- systems;
- relationships.
