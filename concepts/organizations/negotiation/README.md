# Negotiation

Negotiation is a process for reaching voluntary agreement when parties have **some conflicting interests and some opportunity for mutual gain**.

Almost every meaningful negotiation contains both:

- **value claiming**; and
- **value creation**.

The balance changes by situation.

# A Reusable Negotiation Sequence

## 1. Prepare

- identify BATNA;
- convert it into a reservation point;
- set an aspiration;
- model the other side;
- identify reference points;
- map issues and priorities;
- assess relationship importance.

## 2. Diagnose

Ask:

- Is this primarily distributive or integrative?
- Is there a positive ZOPA?
- Are there multiple issues?
- Is information asymmetric?
- Is this repeated or one-shot?
- Are there more than two parties?
- Who can block an agreement?

## 3. Exchange Information

- ask;
- listen;
- rephrase;
- observe;
- share selectively;
- test preferences with hypothetical packages.

## 4. Create Value

- trade on differences;
- add issues;
- use contingent terms;
- bundle packages;
- search for Pareto improvements.

## 5. Claim Value

- manage anchors;
- make reciprocal concessions;
- use objective criteria;
- protect the reservation point;
- know when to stop.

## 6. Preserve the Process

- manage emotion;
- maintain credibility;
- recognize fairness concerns;
- protect important relationships;
- avoid humiliating the other side.

# My Current View

Negotiation is not primarily about being aggressive or agreeable.

It is about **preparation, diagnosis, information, and adaptive behavior**.

The best negotiator can:

- compete when value must be claimed;
- collaborate when value can be created;
- walk away when no good deal exists; and
- change strategy as new information arrives.
