# Creating and Claiming Value

## Definition

Negotiation has two economic tasks.

### Creating Value

Increase the total surplus available to the parties.

### Claiming Value

Determine how that surplus is divided.

The two are complementary.

---

## Why It Matters

Pure competition can leave value on the table.

Pure cooperation can create value that the other side captures.

Good negotiation requires the ability to do both.

---

## Framework

### Create Value When

- multiple issues exist;
- priorities differ;
- time preferences differ;
- risk tolerances differ;
- forecasts differ;
- capabilities differ.

Tools:

- package offers;
- trade-offs;
- side issues;
- contingent contracts;
- post-settlement improvements.

### Claim Value With

- strong alternatives;
- reservation discipline;
- aspiration;
- anchoring;
- objective criteria;
- reciprocal concessions.

---

## How I Think About It

"Win-win" is too vague.

A better standard is:

> **Did we identify a package that created more total value than the obvious compromise?**

Then:

> **Did I claim an appropriate share of the value I helped create?**

---

## Rules of Thumb

- Create before dividing when possible.
- Do not confuse compromise with integration.
- Trade low-value items for high-value items.
- Use information about priorities.
- Do not disclose reservation points merely to seem cooperative.
- Use contingent terms for genuine forecast disagreement.
- Search for a better package even after tentative agreement.

---

## Example

If an additional contract feature gives the buyer $800K of value but costs the seller $400K, the feature creates $400K of joint surplus.

The parties can then use price or another term to divide that new surplus.

---

## Failure Modes

### Fixed-Pie Bias

Assuming every gain to them is a loss to me.

### Premature Price Bargaining

Fighting about division before understanding all issues.

### Sequential Issue Bargaining

Closing one issue at a time and eliminating trade opportunities.

### Collaboration Without Claiming

Creating value while surrendering most of it.
