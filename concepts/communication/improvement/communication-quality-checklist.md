# Communication Quality Checklist

Use this before an important communication.

## Strategy

- [ ] I know the audience.
- [ ] I know the desired result.
- [ ] I can state the Big Idea in one sentence.
- [ ] The audience benefit or relevance is clear.

## Structure

- [ ] The main point appears early.
- [ ] The organization is visible.
- [ ] Supporting points are limited and logical.
- [ ] The ending gives a next step.

## Content

- [ ] The information is relevant.
- [ ] Recommendations are specific.
- [ ] Evidence is sufficient.
- [ ] I answered likely objections.

## Style

- [ ] Language is plain.
- [ ] Sentences are concise.
- [ ] Tone fits the audience.
- [ ] Active voice clarifies responsibility.

## Format / Visuals

- [ ] Subject line or title communicates meaning.
- [ ] The document is easy to skim.
- [ ] Slides are readable.
- [ ] Each slide has one primary "so what?"
- [ ] Visuals reinforce the message.

## Delivery

- [ ] I am using eye connection intentionally.
- [ ] My pace allows comprehension.
- [ ] I can pause instead of filling silence.
- [ ] My posture and gestures support the message.
- [ ] I can handle the unexpected.

## Interaction

- [ ] I anticipated likely questions.
- [ ] I know how to reframe loaded or false-choice questions.
- [ ] I know what I will do when I do not know.
- [ ] I can bridge answers back to the Big Idea.

## Team

- [ ] Everyone understands the whole message.
- [ ] Transitions are planned.
- [ ] Visuals are consistent.
- [ ] Q&A responsibility is shared.
- [ ] Non-speakers remain engaged.

## Final Test

Can the audience:

- understand;
- remember;
- trust;
- act?

If one of those is unclear, the communication is not finished.
