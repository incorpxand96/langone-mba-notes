# ROIC vs. ROE and Leverage

## ROIC

`ROIC = Operating Profit After Tax / Invested Capital`

Measures operating return before financing structure.

## ROE

`ROE = Net Income / Equity`

Measures shareholder return after financing effects.

## Leverage Effect

If operating return exceeds debt cost:

- leverage can raise ROE.

If operating return falls below debt cost:

- leverage lowers ROE.

## Risk

Debt adds fixed financing cost.

Therefore leverage amplifies equity return volatility.

## Liquidity

Cash/financial assets reduce volatility but also tie capital to lower-return uses.

## Principle

> **Higher ROE is not automatically better operating performance.**

First ask whether the change came from:

- ROIC;
- leverage;
- interest cost;
- liquidity.
