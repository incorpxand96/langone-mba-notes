# Strategy I: Competitive Strategy

This folder contains my working knowledge base for **Strategy I: Competitive Strategy (COR1-GB 2103)**, taught by **Professor Callen Anthony** at NYU Stern during the Winter Intensive in 2025.

The course is organized around one fundamental question:

> **Why are some firms more successful than others?**

The answer is not one framework. Firm performance emerges from the interaction among:

- industry structure;
- competitive positioning;
- the activity system used to implement that position;
- resources and capabilities;
- platform/network dynamics where relevant;
- rival reactions and managerial choices.

# The Course's Core Diagnostic

A strategy problem can originate in different places.

```text
I have a strategy problem
        ↓
┌───────────────────────────────┐
│ Is it an industry-structure   │
│ problem?                      │
└───────────────────────────────┘
        ↓
Rivalry / buyers / suppliers /
entry / substitutes
        ↓
OR
        ↓
┌───────────────────────────────┐
│ Is it a competitive-advantage │
│ problem?                      │
└───────────────────────────────┘
        ↓
Position / scope / activities /
resources / capabilities
```

This is more useful than applying Five Forces mechanically to every problem.

# My High-Level Takeaways

1. **Industry structure explains differences in average profitability across industries.**
2. **Competitive advantage explains why firms within the same industry perform differently.**
3. **Even one unfavorable force can materially reduce an industry's profit pool.**
4. **Five Forces is a causal framework, not a scoring exercise.**
5. **A firm must understand the entire value system, not only the product it manufactures.**
6. **Product advantage is not automatically competitive advantage.**
7. **Competitive positioning is about choosing a distinct way to create value.**
8. **Value creation can be framed as a WTP–C wedge.**
9. **Differentiation is attractive only when the increase in willingness-to-pay exceeds the cost required to create it.**
10. **Low cost and differentiation are alternative routes to enlarging the value-creation wedge—not slogans.**
11. **Operational effectiveness is necessary but usually imitable.**
12. **Strategy requires tradeoffs: a position becomes defensible partly because a rival cannot copy it without damaging its existing system.**
13. **Fit among activities makes a strategy more valuable and harder to imitate.**
14. **Resource value is contextual, not inherent.**
15. **Resources matter when they allow a firm to create more value or lower cost in a particular competitive environment.**
16. **A resource advantage must be maintained, upgraded, and appropriately captured.**
17. **Blindly carrying legacy resources into an attractive new market is not strategy.**
18. **Platform businesses create value by facilitating exchanges among groups.**
19. **Network effects mean scale can raise customer value, not merely reduce cost.**
20. **Platform pricing should maximize network value, not necessarily charge every side equally.**
21. **Winner-take-all dynamics become stronger when network effects are strong and multi-homing is costly.**
22. **A platform must actually reduce transaction costs and remain economically feasible; "platform" is not itself a strategy.**
23. **Rivals react. Strategy must therefore model interdependence rather than assume static competitors.**
24. **A threat matters only if it is credible in the rival's economics and incentives.**
25. **Entering with a position that closely resembles incumbents can invite ruinous rivalry.**
26. **Financial results can reveal strategy: margin, asset turns, and capital structure often expose different strategic paths.**
27. **ROE can obscure strategic performance because financing choices affect it; operating returns are often cleaner for strategic comparison.**
28. **Strong strategy combines external fit with internal distinctiveness.**
29. **Growth can destroy strategy when it erodes tradeoffs, fit, or resource advantage.**
30. **The goal is not to use every framework. It is to identify the framework that explains the economic problem.**
