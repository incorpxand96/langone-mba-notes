# Real Options and Strategic Flexibility

Traditional DCF assumes a relatively fixed path of future cash flows.

Real-options thinking recognizes that managers can learn and adapt.

## Managerial Options

A project can create options to:

- expand;
- defer;
- abandon;
- redeploy;
- sequence investment;
- enter adjacent markets.

## Why DCF Can Undervalue Flexibility

A risky project may have:

- limited downside because management can stop investing;
- large upside if early results are strong.

Static NPV can miss that asymmetry.

## Why Real Options Can Be Abused

Option logic can also justify overinvestment when managers:

- overstate volatility/upside;
- ignore cost uncertainty;
- assume flexibility that does not exist;
- treat every speculative project as strategically priceless.

## Integrated View

Real options should complement rather than replace DCF.

The value lies in explicit managerial flexibility.

## Disney / Creative IP

A successful character or film can create options across:

- sequels;
- merchandising;
- parks;
- streaming;
- games;
- international markets.

The original creative investment therefore has value beyond its first cash-flow stream.

## Principle

> **An option is valuable because management can change course after learning—not merely because the future is uncertain.**
