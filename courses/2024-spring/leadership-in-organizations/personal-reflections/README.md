# Personal Reflections

This folder preserves my **Spring 2024** reflections from Leadership in Organizations.

These are historical artifacts, not claims that every priority or belief remains unchanged today.

The purpose is to capture:

- how I saw myself;
- what I valued;
- what tradeoffs I identified;
- what leadership principles I was developing.

That makes it possible to compare later experience against an earlier self-assessment.

## Why Preserve This?

Leadership development is difficult to evaluate retrospectively because memory rewrites our prior intentions.

A dated record creates evidence.

I can later ask:

- Which values remained stable?
- Which goals changed?
- Which predicted risks actually appeared?
- Which weaknesses were real?
- Which concerns were overstated?
- How did my definition of leadership change?
