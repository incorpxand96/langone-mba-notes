# Leadership Retrospective Prompts

Use these prompts to revisit the Spring 2024 materials later.

## Values

- Which 2024 values remain central?
- Which became less important?
- Which values did my behavior reveal that I failed to name?

## Balance

- Did "balance" prove useful or too vague?
- Which pillar usually won when tradeoffs became real?
- Did I systematically underinvest in any category?

## Motivation

- How has the role of compensation changed?
- Which intrinsic motivators actually sustained effort?
- Which incentives created unintended behavior?

## Leadership

- Where did I lead without formal authority?
- Where did I rely too heavily on authority or role?
- What leadership behavior now feels most natural?
- Which behavior still requires deliberate effort?

## Feedback

- Which feedback about myself did I resist but later accept?
- Where is there still a gap between how I see myself and how others see me?

## Systems

- When did I blame a person for a system problem?
- When did I hide behind "the system" instead of holding someone accountable?

## Culture

- Which cultures helped me perform?
- Which culture signals mattered more than stated values?
- What behaviors would I explicitly reward if I ran the organization?

## Decision-Making

- Which bias most often affects me?
- What decision process has helped me counter it?
- Where did a group improve my judgment?
- Where did a group make it worse?
